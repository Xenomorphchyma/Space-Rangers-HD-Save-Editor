# Support

- Ошибки: [создать bug report](https://github.com/Xenomorphchyma/Space-Rangers-HD-Save-Editor/issues/new?template=bug_report.yml).
- Предложения: [создать feature request](https://github.com/Xenomorphchyma/Space-Rangers-HD-Save-Editor/issues/new?template=feature_request.yml).
- Уязвимости: используйте [приватный security advisory](https://github.com/Xenomorphchyma/Space-Rangers-HD-Save-Editor/security/advisories/new), а не публичный issue.

Не публикуйте личные SAV. Указывайте версию редактора, версию игры, активные
моды, шаги воспроизведения и обезличенный скриншот или текст ошибки.
