# Attribution and scope

Space Rangers HD Save Editor is an independent, unofficial compatibility
implementation for Space Rangers HD save files.

Compatibility research used the behavior of the desktop **Cassandra v1.11** by
`indiemagpie` as a historical reference:

<https://github.com/indiemagpie/Cassandra>

That repository does not currently publish an open-source license. Its
executable, icons, screenshots and binary form resources are not redistributed
in this repository. Cassandra was inspected as a behavioral reference for
interoperability only.

The Russian captions and localization tables implement UI compatibility and
were developed with Cassandra among the historical behavior references listed
above. They are identified for provenance and are not claimed as original
Cassandra authorship by Xenomorphchyma. They are excluded from the MIT grant
pending clarification or permission from the Cassandra author. No Cassandra
executable, icon, screenshot, DFM binary or game asset is included.

The MIT license in this repository applies to the independently written project
code except for the compatibility data tables explicitly identified above. It
does not grant rights to Space Rangers HD, Cassandra, or third-party game/mod
content.

Space Rangers and related names and assets belong to their respective owners.
This project is not affiliated with or endorsed by the game's publishers,
developers, or the author of Cassandra.
