# Security policy

Редактор работает с недоверенными бинарными файлами. Сообщайте приватно о
переполнениях, обходах проверки границ, повреждении исходного SAV, выполнении
кода или неожиданном сетевом доступе. До появления отдельного security-адреса
используйте [приватный security advisory репозитория GitHub](https://github.com/Xenomorphchyma/Space-Rangers-HD-Save-Editor/security/advisories/new).

Не прикладывайте пользовательские SAV к публичным issue. Сначала создайте
минимальный обезличенный воспроизводимый пример или предложите безопасный канал
передачи.

Обычные ошибки, не связанные с безопасностью, отправляйте в
[GitHub Issues](https://github.com/Xenomorphchyma/Space-Rangers-HD-Save-Editor/issues).
