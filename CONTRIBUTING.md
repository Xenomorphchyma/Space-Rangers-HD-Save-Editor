# Contributing

Проект сопровождает **Xenomorphchyma**. Отправляя изменение, участник соглашается
распространять собственный вклад по лицензии MIT проекта.

1. Не добавляйте в репозиторий SAV, файлы игры, моды или ресурсы
   Cassandra или персональные абсолютные пути.
2. Соберите проект командой `.\tools\build.ps1`.
3. Запустите `.\tools\verify.ps1`; при изменении сериализатора дополнительно
   используйте локальный корпус сохранений.
4. Новые неизвестные структуры сначала реализуйте как lossless/read-only:
   редактор обязан сохранить исходные байты до появления проверенного writer.
5. Для каждого нового изменяемого поля добавьте тест parse → patch → write →
   parse и проверку неизменности непричастных байтов.
6. Не копируйте код, ресурсы или переводы из Cassandra либо игры без явной
   совместимой лицензии и записи в `THIRD-PARTY-NOTICES.md`.

Описание pull request должно перечислять проверенные типы SAV (обычные,
модовые, старые версии) без прикладывания самих пользовательских файлов.
